version 16, released under **CC0 1.0 Universal** (public domain dedication).

only identifies technologies listed on the CV and does not imply endorsement.

MuleSoft, Microsoft Azure, VS Code and PayFast are not distributed by Simple Icons, so
the site shows a neutral line icon for them instead of a brand mark.
